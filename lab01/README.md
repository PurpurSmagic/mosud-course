# Практическая работа № 1

Усачев И.А., группа ИНБО-21-23, вариант по курсу — 8. Работа № 1 общая для всех вариантов.

Сервер — локальный PostgreSQL 17.5 для Windows. База данных `olist`, схемы `olist` и `lab`.

Подключение — `127.0.0.1:55432`, пользователь `postgres`. Параметры запуска и подключения приведены в [README репозитория](../README.md).

Импорт выполнен через `\copy` в `psql` с кодировкой UTF-8. Скрипт [`schema.sql`](schema.sql) запускается из корня репозитория на пустой базе `olist`. Источник CSV — [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce), лицензия CC BY-NC-SA 4.0.

Фактическое число строк — `customers` и `orders` по 99 441, `order_items` 112 650, `order_payments` 103 886, `order_reviews` 99 224, `products` 32 951, `sellers` 3 095, `geolocation` 1 000 163, `product_category_name_translation` 71.

Проверки в [`check.sql`](check.sql) подтвердили совпадение числа строк с методичкой по всем 9 таблицам. Число `NULL` во всех 14 ключевых полях и число ссылок без родительской записи по всем 6 внешним ключам равны нулю. [Запросы и фактический вывод](results.md) можно просмотреть прямо на GitHub.

DDL соответствует приложению А. Добавлены 8 первичных и 6 внешних ключей. В схеме `olist` созданы только индексы первичных ключей. Для всех 9 таблиц выполнен `ANALYZE`.

Исходные таблицы хранятся в схеме `olist`. Изменяемые объекты для следующих практик создаются в схеме `lab`.
