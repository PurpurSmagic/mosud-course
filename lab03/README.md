**Выборка, проекция, переименование и реляционная алгебра**

Исходное отношение — `olist.geolocation`. Предикат — штат `RJ` и широта от −23° до −22° включительно. Диапазон выбран для этой работы согласно условию варианта.

## 1. Исходное отношение и атрибуты

`geolocation(geolocation_zip_code_prefix, geolocation_lat, geolocation_lng, geolocation_city, geolocation_state)`.

| Атрибут | Использование |
| --- | --- |
| `geolocation_zip_code_prefix` | ZIP-префикс в результате, имя `zip_prefix` |
| `geolocation_lat` | Фильтр по широте и результат, имя `lat` |
| `geolocation_lng` | Долгота в результате, имя `lng` |
| `geolocation_city` | Город в результате, имя `city` |
| `geolocation_state` | Фильтр по штату |

## 2. Выражение реляционной алгебры

Обозначим `R = olist.geolocation`, `s = (geolocation_state = 'RJ')`, `p = (−23 ≤ geolocation_lat ≤ −22)`, `L = {geolocation_zip_code_prefix, geolocation_lat, geolocation_lng, geolocation_city}`. Операция `ρ` переименовывает атрибуты `L` в `zip_prefix, lat, lng, city` в том же порядке.

**Исходное выражение**

```text
Q = ρ(π_L(σ_(s ∧ p)(R)))
```

Дерево операций снизу вверх — `R → σ_(s ∧ p) → π_L → ρ`.

**Две последовательные выборки**

```text
Q′ = ρ(π_L(σ_p(σ_s(R))))
```

**Ранняя проекция**

```text
Q″ = ρ(σ_p(π_L(σ_s(R))))
```

После фильтра `σ_s` столбец штата исключается из промежуточного отношения. Широта сохраняется в `L` для фильтра `σ_p`. В SQL раннее переименование позволяет записать последний предикат как `lat BETWEEN -23 AND -22`.

## 4. Дубликаты и эквивалентность

Три SQL-реализации возвращают одинаковые 110 389 строк, поскольку последовательные фильтры эквивалентны конъюнкции, а ранняя проекция сохраняет атрибут следующего предиката. Проверка через `EXCEPT ALL` в обоих направлениях дала по нулю строк для каждой пары с исходным запросом, что подтверждает совпадение и значений, и их кратностей. В проекции есть 16 513 групп одинаковых кортежей, максимальная кратность равна 89. `SELECT DISTINCT` оставляет 72 073 уникальных кортежа и устраняет 38 316 повторных вхождений. Математической проекции соответствует результат с `DISTINCT`, поскольку отношение в реляционной алгебре является множеством.

| Показатель | Фактическое значение |
| --- | ---: |
| Исходный `SELECT` | 110 389 |
| Две последовательные выборки | 110 389 |
| Ранняя проекция | 110 389 |
| `SELECT DISTINCT` | 72 073 |
| Повторные вхождения | 38 316 |
| Группы с кратностью больше одного | 16 513 |

## 5. Ответы на контрольные вопросы

1. **Какие свойства выборки позволяют менять порядок нескольких фильтров?** Для конъюнкции предикатов выполняются `σ_(p ∧ s)(R) = σ_p(σ_s(R)) = σ_s(σ_p(R))`. Каждая выборка сохраняет только строки, удовлетворяющие её предикату.
2. **Почему проекция в математической модели устраняет повторяющиеся кортежи, а `SELECT` в SQL сохраняет их?** Математическое отношение является множеством, в котором одинаковый кортеж встречается один раз. SQL сохраняет кратность строк, а `DISTINCT` устраняет повторы.
3. **Что означает замкнутость операций реляционной алгебры?** Результат операции над отношениями тоже является отношением. Поэтому его можно использовать как вход другой операции и строить составные выражения.
